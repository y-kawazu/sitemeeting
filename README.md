# Site Meeting Board

クライアントとのWebサイト制作打ち合わせで使う、サイトマップ兼議事整理アプリです。

## 打ち合わせの流れ

1. クライアント・案件情報と、サイトの目的を入力
2. ひな形を起点に必要なページを追加・整理
3. 各ページを「確定」「要確認」「提案」に分類
4. 確認事項・決定事項・次回までの宿題を記録
5. 「打ち合わせ記録を保存」または「印刷 / PDF」で共有

## データについて

- 入力内容はブラウザのローカルストレージへ自動保存されます。
- 「データ」から編集用JSONを保存・読み込みできます。
- 共有用HTMLには、打ち合わせ概要、サイトマップ、確認・決定・宿題がまとまります。

外部サーバーへのデータ送信はありません。
